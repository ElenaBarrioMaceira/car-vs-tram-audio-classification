# Car vs Tram Audio Classification

## Project Description

Binary classification of car and tram sounds using audio signal
processing techniques and a Support Vector Machine (SVM).

## Dataset

The dataset consists of audio recordings of cars and trams.

## Methodology

1. Audio preprocessing
2. Feature extraction
3. Dataset splitting
4. SVM training
5. Model evaluation

## Audio Features

- Root Mean Square (RMS)
- Zero-Crossing Rate (ZCR)
- Spectral Centroid
- Mel-Frequency Cepstral Coefficients (MFCCs)
